# Online Tools

WP-Mindwerks is a Wordpress plugin that allows the users to:

- [Password Cracking Calc](http://www.mindwerks.net/online-tools/password-cracking-calculator/ "Password Cracking Calculator"): Calculate time required to guess a password
- [Subnet Calc](http://www.mindwerks.net/online-tools/ip-calc/ "Subnet Calculator"): Calculate subnet based on IP address and other bits

This plugin and all it's contents are opensource (GPLv2) and can be found in the [wp-mindwerks](https://bitbucket.org/psi29a/wp-mindwerks) repository. Each project inside the plugin are re-usable and not exclusive to Wordpress. They should work just fine any other CMS or on their own.
